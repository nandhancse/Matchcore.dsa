WHY THESE STRUCTURES?

Two queues. Two jobs.

Instead of using two structures artificially, MatchCore gives each one a clear responsibility inside the same real-life system.

01
↻

Circular Queue

Regular players enter at the rear and leave from the front. Freed array positions are reused by wrapping around.

rear = (rear + 1) % capacity
  • enqueue() Add normal player
  • dequeue() Send player to match
  • front / rear Track active boundaries
02
⇆

Deque

Reconnect or high-priority players can enter from the front, while lower-priority special players can enter from the rear.

addFront() · addRear() · removeFront()
  • addFront() VIP / reconnect
  • addRear() Special queue entry
  • removeBothEnds() Flexible control
PROJECT ABSTRACT — WEB DEMO

Multiplayer Game Matchmaking System

MatchCore is a frontend simulation of the Java DSA project concept. It demonstrates how a Circular Queue can manage regular matchmaking efficiently while a Deque handles reconnect and priority cases.

The browser version visualizes every operation so the logic is easy to explain during a project demo or viva. The same operations map directly to array-based Circular Queue and Deque implementations in Java.
