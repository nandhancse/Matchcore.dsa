# MatchCore — DSA Matchmaking Simulator

Interactive frontend for the **Multiplayer Game Matchmaking System** DSA mini-project.

## Data structures
- **Circular Queue** — normal players are handled in FIFO order with wrap-around slot reuse.
- **Deque** — priority, reconnect, and VIP players can be inserted or removed from either end.

## Features
- Live Circular Queue visualization
- Front and rear pointer tracking
- Deque front/rear operations
- Four-player match creation
- Operation trace for demonstration and viva
- Responsive mobile and desktop interface
- Plain HTML, CSS, and JavaScript — no framework or build step
